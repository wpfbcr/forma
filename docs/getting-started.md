# 使用指南

## 建立你的 Agent 与团队

先在模型中心添加 API 或导入已有登录来源，再创建 Agent，定义职责、输出要求、工作方式、记忆与文件工具。若选择原生 Codex / Claude Code，请先在终端安装并登录。两类 Agent 都由个人创建和配置。

在“我的团队”选择成员并指定 Leader。画布用来调整布局、查看角色，快捷列表用来快速编辑。成员职责与模型可在团队内覆盖；不设置覆盖则沿用 Agent 配置。画布位置不是执行依赖，实际步骤由 Leader 针对每轮要求规划。

## 工作台如何运行

1. 输入目标，选择单个 Agent 或团队，并给本次工作空间命名。
2. 开始后建立真实目录，固定成员与模型配置快照。
3. Leader 规划分工；系统校验成员、步骤 ID 与依赖是否有效。
4. 成员按依赖和并发限制执行，再由 Leader 汇总交付。
5. 你继续与 Leader 对话，下一轮沿用当前任务的对话、上下文和成果。

右侧工作空间包含：

| 页面 | 用途 |
| --- | --- |
| 资料 | 本次参考内容、计划过程、上下文、完整记录与成果版本 |
| 上下文 | 当前轮目标、补充要求、前序摘要、记忆及每个成员的知识范围 |
| 执行 | 分派要求、依赖、成员状态、错误与最近记录 |

可以收起右侧工作空间扩大对话区。文件可预览、查看历史版本，整个任务可导出 ZIP；原始成员目录可从真实工作目录访问。

### 补充、暂停、停止与恢复

执行中发送的新要求会排队，当前轮结束后进入下一轮。暂停等待在途步骤收尾，不再派发新步骤；停止会取消请求并尝试终止子进程树。

失败保留已有步骤与文件，不伪造成功结果。应用重启后遇到未完成任务会保留中断状态；继续前先检查已产生的改动。取消或恢复不等于撤销或回滚外部动作。

## 知识库

新建知识库后可以关联一个只读目录，或导入 Markdown、TXT、CSV、JSON、HTML、文本型 PDF 和 DOCX。上传资料保留受管原件，目录模式可手动或自动同步，原目录中的内容不会被 Wiki 生成覆盖。

不生成 Wiki 时，Agent 会使用当前关键词检索得到的原文证据与来源版本。生成 Wiki 是可选的内容整理步骤，不是检索的前置条件，也不能自动补齐语义召回缺陷。能力和规模限制见[基准报告](retrieval-benchmark.md)。

### 分配给谁使用

- 知识库“分配使用”可查看及设置使用对象。
- Agent 自带知识可在“知识”入口配置。
- 团队共享知识可选全体、仅 Leader 或指定成员。
- 团队成员可以关闭继承 Agent 自带知识，或排除指定库。
- 任务可临时附加知识；每轮保存来源与版本快照，更新对下一轮或新任务生效。

### 整理为 Wiki

选择“整理为 Wiki”，使用全局默认模型、单独模型或指定 Agent。提交后立即返回，可以切换页面；知识库与顶部“处理记录”会展示阶段、耗时、所用目标、错误和结果。

生成内容先保存为草稿，审阅后采纳为 Wiki 正文。当前实现为主题概览：前 30 份资料、每份最多 4000 字符。不会自动整理为完整多页面图谱。

## 技能与记忆

技能有三种来源：手写 `SKILL.md`、描述需求后让 AI 生成草稿、启用预置技能。AI 草稿默认不启用；检查内容后再选择使用。预置技能涵盖资料问答、文档对比、研究报告、写作编辑、会议纪要、需求计划、代码审阅与复盘。

当前技能是指令和输出模板，不执行任意脚本。启用之后还需绑定到 Agent、团队或任务，才会参与实际执行。每轮固定技能内容与版本，后续修改不改写旧记录。

记忆是手动创建和附加的偏好、工作约定；目前没有自动抽取跨会话记忆的能力。

## 后台处理记录

Wiki 和 AI 技能生成会持久化阶段与状态。可查看详情、取消、手动重试并打开结果；重试创建新记录。退出应用会中断请求，重启后保留中断记录，不自动再次调用模型。

当前为单机进程内后台任务，不是跨进程常驻工作队列。只有应用运行时才会继续处理。

## 本地数据与备份

默认配置目录通常为 macOS 的 `~/Library/Application Support/Forma`、Windows 的 `%APPDATA%/Forma`。源码开发构建的名称可能不同；开发者可用 `FORMA_DATA_DIR` 隔离数据。

```text
应用数据目录/
  state.json                    # Agent、团队、任务与设置
  credentials.enc.json          # 系统安全存储加密的模型密钥
  resources/                    # 资料索引、Wiki、技能与生成记录相关文件
  workspaces/<任务 ID>/
    资料/
    上下文/
    会话/
    轮次/<轮次编号>/
    成员/<Agent ID>/
    成员产物/
    成果/
    .forma/versions/
```

工作空间根目录可在设置里更改；备份时需同时包含自定义工作空间和应用数据。退出应用后再复制，避免读到正在写入的状态。系统加密密钥不保证跨设备可解密，迁移后可能需要重新填写。

导出工作空间不包含模型密钥，但会包含该任务资料、对话与上下文；分享前自行检查这些内容。云模型会接收任务所需资料，详见[安全说明](../SECURITY.md)。

# 路线图

这是开发方向，不是发布日期或兼容性承诺。已经实现的行为以 README、更新日志和验证记录为准，欢迎通过 [Issues](https://github.com/wpfbcr/forma/issues) 提供实际场景。

## 当前 Alpha 已有

- 自建/原生 Agent、个人团队、Leader 持续对话及真实任务空间。
- API 与已有 CLI 登录来源、平台默认模型、可选本机 Magpie 网关发现。
- 范围化知识分配、关键词检索、可审阅 Wiki 概览、指令技能和后台处理记录。

## 优先：可安装、可诊断、可恢复

- Windows 与 Intel Mac 实机验证、正式签名、公证及升级路径。
- 真实服务商、原 CLI 和 Magpie 网关的端到端兼容验证。
- 更完整的失败诊断、生成阶段反馈、流式回复与中断恢复体验。
- 状态与配置迁移、统一容量限制、应用数据备份与恢复。

## 然后：提高知识证据质量

- 结构化切片与段落级评分，修复长文证据位置和多库融合问题。
- 本地全文索引、中文策略、增量更新和同轮共享检索缓存。
- 按成员任务进行受限主动检索，并保留准确的来源位置。
- 可选向量与混合检索、重排、OCR；用真实标注集验证收益。
- 分批、多页面 Wiki 整理、引用检查与修订浏览。

这些方向的依据与复现案例见[检索报告](retrieval-benchmark.md)。

## 后续：扩展工作台

- 有范围的 MCP 与搜索工具接入，以及更明确的授权交互。
- 技能资源包、可审阅安装来源及运行隔离。
- 可选的任务计划、预算与用量统计。
- 界面国际化、可导入导出的 Agent/团队模板。
- 更完善的本机模型网关集成；账户池与订阅协议需要独立设计和验证。

不会将规划入口显示为已可用；新增原生、网络和脚本能力需同时说明权限、数据范围、取消与恢复语义。

## 0.2.0-alpha.4 模型连接与发现

- 统一响应读取，区分 HTML、空响应、错误对象与无效 JSON；兼容 BOM、文本块和两种协议的 SSE 返回。请求明确发送 stream:false，遇流式完成标记主动关闭读取。
- 处理根地址、版本前缀、完整接口路径，避免重复拼接；保存完整自定义接口时保留原意。
- 新增无需先保存连接的模型列表读取：鉴权、Anthropic 分页、去重、排序、搜索和选择。
- 显示名称及服务商可自动补全；读取列表不发聊天请求、不持久化输入密钥。修改连接信息需重新获取，改变地址或协议不能静默复用旧密钥。
- 53 项固定响应回归测试通过。尚未对用户实际服务商进行带密钥联调，具体错误原因需结合新版诊断确认。

- 原生桌面使用仅本机固定响应服务验证：填写根地址 → GET 模型列表返回 2 个模型 → 下拉选择 → 自动补全名称/服务商 → 保存 → 文本连接测试成功。没有真实密钥或外部模型调用。
- 桌面截图：`output/model-discovery.png`。本机测试服务仅供验证，不是实际服务商配置。

# 分类技能仓库

0.2.0-alpha.7 增加 16 项 GitHub 精选指令技能，提供中文名称、用途摘要、示例、标签和来源信息。内容已随应用收录，可以离线浏览；实际生成仍使用你选择的模型或 Agent。

## 默认分类与精选内容

| 分类 | 技能 |
| --- | --- |
| 写作与表达 | 技术文档写作、文案精修 |
| 研究与知识 | 用户研究归纳、多来源证据综合 |
| 产品与规划 | 产品需求文档、产品路线规划 |
| 设计与体验 | 界面视觉设计、设计评审、产品微文案 |
| 开发与质量 | 系统化排错、交付前验证 |
| 营销与增长 | 营销文案创作、内容策略规划、产品发布策划 |
| 数据与分析 | SQL 编写与优化、数据图表设计 |

另有“未分类”用于未指定类别的技能。可以新增分类、改名和更改配色。删除分类时技能会移至“未分类”，技能本身和原有绑定继续保留。

## 浏览和使用

左侧按分类筛选，右侧可搜索中文名、技能标识、用途、标签和来源。来源分为全部技能、GitHub 精选、我创建的、基础模板；还可筛选启用状态。“全部技能”优先呈现精选与个人技能，原有 8 个基础模板保留在专门入口。

1. 打开技能详情，查看用途、使用示例和所需工具。
2. 检查技能内容；第三方内容可查看固定提交的原文、来源与许可。
3. 启用技能，并在 Agent、团队或任务的技能选择中绑定。
4. 绑定界面也按分类组织，支持分类和文本筛选；隐藏已选项不会取消原选择。

精选技能默认未启用，不会自动加入已有任务。启用与绑定是两个设置：启用后还需绑定，绑定未启用技能时它仍不参与执行。

## 自己编写、复制与 AI 草稿

手写技能可设置显示名称、分类、标签与 SKILL.md 内容。精选和基础模板正文为只读，使用“复制并编辑”建立个人版本；来源与许可会随副本及后续编辑保留。

AI 编写时也可以选择分类。提交目标和分类会记入后台记录，生成结果为未启用草稿。若分类在处理期间被删除，结果归入未分类，不会因此丢失草稿。

SKILL.md 使用 YAML `name` 和 `description` 加 Markdown 正文；`name` 为英文小写短横线标识，显示名称可使用中文。内容上限为 100000 字符；较长技能会占用更多上下文，任务仍有总上下文上限。

## 工具与兼容范围

收录的是指令方法，不是完整的上游插件运行环境。Forma 没有因为导入技能就安装浏览器、MCP、数据库、Python 或任意脚本。选择了原生 Agent 时，实际能力取决于原工具和当前授权。

例如 SQL 技能可依据表结构生成查询；没有数据库环境时不能声称查询已执行。数据图表技能可以给出图表方案和绘图代码，实际出图需要 Agent 的执行环境。研究类技能使用实际提供的证据，不自动成为联网搜索服务。

上游 Markdown 参考已经内联，缺失的连接器不作为强制前置条件。用户指令、角色输出协议、权限与授权仍优先于技能中的工作流程。

## 来源与许可

来源为 Anthropic 的 `skills` 与 `knowledge-work-plugins`、Superpowers、Marketing Skills。每项保留完整 GitHub 提交、原文 SHA-256、适配文本 SHA-256、原文和适用许可。原文与适配说明见[收录清单](../resources/skills/README.md)。技能材料保持其 Apache-2.0 / MIT 许可，不统一改为 Forma 自有许可。

当前没有在线技能市场、用户任意 GitHub URL 的动态安装、自动追踪上游更新或执行资源包的能力。目录由维护者审阅和固定版本，用户可以复制到个人版本继续修改。

# Forma 0.2.0-alpha.6

首次公开 Alpha：一个面向个人的 AI 桌面工作台。自己创建 Agent 和团队，只与 Leader 持续对话，在同一个任务空间保留资料、上下文、执行记录和成果。

## 包含的能力

- 自建 Agent、Codex / Claude Code 接入、个人团队、Leader 分派与持续对话。
- 本地任务空间、上下文与来源快照、成果版本、文件预览和 ZIP 导出。
- API 模型列表发现、全局默认模型、已有 CLI 登录导入及可选 Magpie 本机网关。
- 范围化知识库、关键词检索、可审阅 Wiki 概览、指令技能及后台处理记录。
- 中英文项目介绍、安装/使用文档、路线图与 MIT 开源许可。

## 使用前了解

- 首次启动为空白空间，需要添加自己的模型或导入已有 CLI 登录；不附带付费模型额度。
- 生成会使用所选账户额度，云服务会收到任务所需资料。普通本地文件和状态目前不做整体加密，API 密钥独立使用系统安全存储。
- 当前检索是关键词方案，无向量检索、重排与 OCR。Wiki 为主题概览草稿，技能为指令模板。
- Magpie 网关不内置；跨原生 Codex / Claude Code 路由需运行本机网关。
- 目前没有 MCP、搜索服务、定时任务、自动更新或逐 token 输出。
- 原生工具沿用自身权限机制，工作目录分离不是完整操作系统沙箱。

## English notes

This is an unsigned early preview. It includes custom and native agents, personal teams, persistent task workspaces, model discovery, scoped knowledge, reviewable Wiki drafts and instruction skills. The UI is primarily Simplified Chinese. Provide your own model service or existing CLI sign-in; no paid credits are included.

The attached macOS arm64 and Windows x64 packages were built by the linked Actions run from `da8d085`. Checks passed on Linux, macOS and Windows, including 71 fixed-response tests per platform. Windows desktop behavior and real model / subscription / gateway generation are not fully validated. Packages are unsigned; macOS is not notarized. Verify SHA-256 values before installation and read the repository's current limitations.

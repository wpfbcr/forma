# Forma 0.2.0-alpha.7

本次更新重做技能仓库：收录 16 项来自 GitHub 的指令技能，按工作场景分类，并支持管理自己的分类。

## 新增与改进

- 7 个默认主题：写作与表达、研究与知识、产品与规划、设计与体验、开发与质量、营销与增长、数据与分析，另有未分类。
- 新增分类、改名、配色、删除并迁移至未分类；保留技能内容和已有绑定。
- 中文技能卡片、用途摘要、示例、标签、所需工具说明、来源与许可详情。
- 搜索、来源和启用状态筛选；Agent / 团队 / 任务的技能选择也支持分类。
- 精选正文只读，复制后成为个人版本，并持续保留原始来源和许可。
- 手写和 AI 生成可选分类。精选默认未启用，启用并绑定后才参与执行。
- 原有 8 项基础模板与绑定保留，不再占据默认目录。

收录来源为 Anthropic Skills、Anthropic Knowledge Work Plugins、Superpowers、Marketing Skills。各项固定 GitHub 提交，保留原文、许可证、SHA-256 与适配记录。见[目录清单](https://github.com/wpfbcr/forma/blob/main/resources/skills/README.md)和[使用指南](https://github.com/wpfbcr/forma/blob/main/docs/skills.md)。

## 验证与限制

新增 8 项回归，累计 79 项固定响应测试通过，覆盖旧数据迁移、分类持久化与删除、来源和许可保留、复制编辑、AI 草稿分类等。独立 UI 使用实际 Renderer 与本地 Service 验证搜索、分类管理、启用和绑定，并检查桌面/窄屏与深色主题。

技能为指令适配，不捆绑上游插件、MCP、数据库、Python 或脚本环境。缺少工具时应说明限制或输出方案/代码，不能声称已执行。上述检查不代表 16 项技能均已完成真实模型效果验收。CI 与安装包来源以 Actions 和附件 BUILD_INFO.json 为准。

## English

This Alpha adds 16 pinned GitHub instruction skills in seven categories, a redesigned library, search and source/status filters, user category management, categorized binding, and editable personal copies with preserved attribution. Manual and AI drafts can choose a category. Existing basic templates and bindings are retained. Curated entries are disabled by default.

The catalog includes Apache-2.0 / MIT materials with originals, licenses and adaptation records. Upstream plugins and execution tools are not installed by importing instructions. There are 79 fixed-response tests; real model effectiveness for every skill remains unverified. Installers are unsigned, macOS is not notarized, and Windows desktop validation remains limited. Verify checksums and build provenance before installation.
